# Afterword

The process of writing this book has been one of continuous questioning, continuous revision, and continuous deepening.

The original motivation was simple — we had already developed a Five Motions and Six Qi syndrome differentiation program, with both Chinese and English versions, deployed on GitHub Pages, freely available to anyone. But what is the logic behind the program? Where do these logics come from? Why did the ancients design such a set of logic? These questions cannot be answered by the program itself; they require a book to answer.

So we began writing this book.

## 1. Several Key Turning Points in the Writing Process

The first turning point was from "ordinary logic and structure" to "true intrinsic function logic."

Initially, we planned to write according to the conventional structure of TCM books — theoretical origins, core concepts, calculation methods, clinical applications, case validation. But as we wrote, we found that such a structure could not answer a core question: Why is the logic of Five Motions and Six Qi asymmetric with the logic of destiny calculation? Although both are stacking of Heavenly Stems and Earthly Branches, the logics are different — these two sets of logic do not operate on the same dimension.

So we began to deeply think about the intrinsic function logic of Five Motions and Six Qi — Principal and Guest are two sets, Motion and Qi are two sets, so there are four sets in total. From a mathematical function perspective, the variability is much greater. Why did the ancients design such a set of logic? Was it discovered or artificially constructed? These questions guided us to continuously deepen.

The second turning point was from "static calculation" to "dynamic balance."

Initially, our Dynamic Stagnation Point calculation adopted a simple "attack-attacked" model — Heavenly Stem excess attacks Earthly Branch, Earthly Branch being attacked causes disease. But such a model is too mechanical and cannot explain why, with the same congenital endowment, some people develop disease and some do not, why some diseases are mild and some are severe.

So we introduced the "dynamic balance model" — disease risk = attack power - regulatory ability. The system is not a passive target, but a living, self-regulating entity. The system's regulatory mechanisms include generation-restriction, victory-restoration, stagnation-eruption, Tong Shi substitution, Six Qi brake, etc. The goal of treatment is not to "eliminate the attacker," but to "restore balance." This model makes the system truly "come alive."

The third turning point was from "single Six Qi Five Elements" to "Six Qi as primary, Four Directions as secondary."

In the actual use of the program, we discovered a problem — the Five Elements attributes of the twelve Earthly Branches are inconsistent between Six Qi and Four Directions (方位/四季). Only four branches (Chou, Wu, Wei, You) are consistent between the two schools, while the other eight are inconsistent. The old algorithm confused these two schools, leading to incorrect Trigger Point calculations in multiple cases.

So we introduced the strategy of "Six Qi as primary, Four Directions as secondary" — Six Qi is the "work content" of the Earthly Branch, and Four Directions is the "hometown background" of the Earthly Branch. The algorithm prioritizes searching using Six Qi Five Elements, and if not found, supplements with Four Directions Five Elements. The introduction of this strategy caused significant changes in the calculation results of multiple cases and also made the logic more rigorous.

The fourth turning point was from "single-module calculation" to "dual-module structure."

When comparing the actual output of the program, we found that the program has two modules — "Core Stagnation Point Analysis" (macro overall judgment from the Annual Motion/Heavenly Stem perspective) and "Six Qi Brake Dynamic Stagnation Point Calculation" (micro specific positioning from the Six Qi/Earthly Branch perspective). But the book only had one calculation module, lacking Core Stagnation Point Analysis.

So we introduced the "dual-module structure" — Core Stagnation Point Analysis answers "overall which element is stagnated and to what degree," and Dynamic Stagnation Point Calculation answers "specifically which Earthly Branch is the lesion, which organ is damaged, which meridians are affected." Only by combining the two can complete calculation results be given.

The fifth turning point was from "Tong Shi substitution" to "Tong Shi backup and warning."

Initially, our Tong Shi concept only had "substitution" — when the Stagnation Point is not in the Four Pillars, Tong Shi takes over. But the actual output of the program showed that even when the Stagnation Point is in the Four Pillars, it also displays Tong Shi backup and warning (mutual backup brakes, need to be alert to concurrent wear).

So we introduced the "Tong Shi backup and warning mechanism" — even if the Stagnation Point is in the Four Pillars, the Tong Shi Earthly Branch also serves as a "backup brake," jointly assuming regulatory function with the Stagnation Point. Need to be alert to "concurrent wear" — when the Stagnation Point and Tong Shi are attacked simultaneously, regulatory ability drops significantly (correction coefficient = 0.5). The introduction of this mechanism makes the system's regulatory ability model more complete.

## 2. Several Important Understandings

During the writing process, we formed several important understandings:

First, **the nouns in ancient texts are actually equivalent to symbols**. Sovereign Heaven, Earthly Deputy, Annual Motion, Central Motion, Great Motion, Principal Qi, Guest Qi, Principal Motion, Guest Motion... these concepts, if explained in Chinese, sometimes only professionals can understand, and they are indeed more like mathematical symbols. The ancients used these nouns to explain for easy understanding — they are both symbols and nouns. Therefore, using the original Chinese nouns (with pinyin and English annotations) is more explanatory and does not produce ambiguity.

Second, **the logic of Five Motions and Six Qi can be numericalized, parameterized, and formulized**. Although the books left by the ancients did not write specific calculation methods, by organizing the rules in Neijing, we can establish a set of calculable and verifiable algorithm frameworks. The parameters in this framework (power values, coefficients, thresholds, weights, etc.) are all marked as [to be verified] and need to be verified and optimized through large-sample clinical data. But the framework itself is clear and reproducible.

Third, **the core of the system is dynamic balance, not static attack-attacked**. The human body grows according to the intrinsic function relationship between Heaven and Earth, so that the state of a person's entire life proceeds according to such a function relationship. The system is living and self-regulating — generation-restriction, victory-restoration, stagnation-eruption, Tong Shi substitution, Six Qi brake are all regulatory mechanisms of the system. The essence of disease is not "being attacked," but "balance being broken." The goal of treatment is not to "eliminate the attacker," but to "restore balance."

Fourth, **the factors of disease are multiple, and temporal medicine is only one of the possibilities**. The probability in temporal medicine may also be just a possibility, but in reality, various factors need to support each other for the correctness to be measured. Therefore, the positioning of this book is a "falsifiable conjecture," not an "already proven truth." What we provide is a starting point for research advancement, not the final answer.

Fifth, **open source and openness is the only way for the development of temporal medicine**. Our program is already open source, deployed on GitHub Pages, and anyone can freely use it, view the source code, and propose modification suggestions. Our book will also be open source, and anyone can freely read, cite, and modify it. Only through open source and openness can more people be attracted to participate in research, can temporal medicine be verified at the microscopic level, and can this set of logic truly serve human health.
