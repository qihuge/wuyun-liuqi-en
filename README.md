# 五运六气辨证系统 - 英文版

**WuYun LiuQi BianZheng System - English Web Version**

一个基于中医五运六气理论的辨证系统，支持中英文双语显示。

## 在线访问

**https://qihuge.github.io/wuyun-liuqi-en/**

## 功能特性

- 📅 **万年历/阴阳历/干支** - 基于 lunar-javascript，准确计算四柱八字
- 🩺 **四诊合参** - 望闻问切 15 个核心字段输入
- ⚖️ **八纲辨证** - 阴阳/寒热/虚实/表里辨证
- 💊 **治法与方剂** - 治法、饮食、穴位、日常建议，50+ 方剂推荐
- 🌿 **五运六气** - 主运/客运/主气/客气，出生/当前/发病三时间维度
- 🔥 **动态郁点演算** - 六气刹车动态郁点分析与对治法则
- 📜 **六气治则** - 司天在泉治则匹配
- 🌐 **中英文双语** - 核心术语"中文 (英文)"双语显示，减少歧义

## 核心术语双语显示

为避免中医术语翻译产生歧义，核心术语采用"中文 + 英文"双语格式：

- 天干：甲 Jia (Yang Wood)
- 地支：丑 Chou (Ox)
- 六气：厥阴风木 (Jueyin Wind-Wood)
- 证型：表实寒证 (Exterior-Excess-Cold Pattern)
