# Terminology Format Specification

> Unified terminology specification for this book, ensuring consistent and unambiguous terminology in both Chinese and English bilingual versions.

## 1. Core Principles

1. **Ancient text nouns are symbols**: Ancient text nouns such as Sovereign Heaven, Earthly Deputy, Annual Motion, etc. are essentially "symbols" — both nouns and operational symbols. Retaining the original Chinese nouns is most explanatory and does not produce ambiguity.

2. **Chinese + Pinyin + English functional description**: Traditional concepts adopt the format of "original Chinese noun + Pinyin + English functional description," allowing foreign readers to see the original symbol and understand its meaning through the functional description.

3. **Original concepts of this book do not add Pinyin**: Original concepts of this book such as Trigger Point, Stagnation Point, Tong Shi Substitute, etc. have no correspondence in traditional TCM, and Pinyin is meaningless. They adopt the format of "Chinese + English functional description."

4. **Complete at first occurrence, simplified thereafter**: Concepts use the complete format when first appearing, and are simplified in subsequent occurrences, avoiding the main text being overwhelmed by annotations.

5. **Unique standard symbol**: Each concept has a unique "standard symbol." Aliases are only noted at first occurrence, and the standard symbol is used uniformly throughout the book.

## 2. Terminology Format

### 2.1 Traditional Concepts (Ancient Text Nouns)

| Occurrence Scenario | Format | Example |
|---------------------|--------|---------|
| First occurrence in book | *Chinese* (Pinyin, English functional description) | *司天* (Si Tian, the 3rd guest qi-step governing the first half of the year) |
| First occurrence in chapter | *Chinese* (Pinyin) | *司天* (Si Tian) |
| Subsequent occurrences | Pinyin or Chinese | Si Tian / 司天 |
| Glossary | Chinese (Pinyin) — English functional description | 司天 (Si Tian) — Sovereign Heaven Qi-Step |

### 2.2 Original Concepts of This Book

| Occurrence Scenario | Format | Example |
|---------------------|--------|---------|
| First occurrence in book | *Chinese* (English functional description) | *诱点* (Trigger Point, the attacking branch that triggers disease) |
| First occurrence in chapter | *Chinese* (English) | *诱点* (Trigger Point) |
| Subsequent occurrences | English or Chinese | Trigger Point / 诱点 |
| Glossary | Chinese — English functional description [Original] | 诱点 — Trigger Point [Original] |

### 2.3 Typesetting Rules

* **Chinese characters**: Italic, enclosed in parentheses, font size consistent with main text

* **Pinyin**: Without tone marks, first letter capitalized, spaces between words

* **English functional description**: First letter capitalized, using functional language rather than literal translation

* **Comma separation**: Comma + space between Pinyin and English description

### 2.4 English Functional Description Writing Specification

English annotations must be **functional descriptions**, not literal translations:

| Concept | ❌ Literal translation (incorrect) | ✅ Functional description (correct) |
|---------|-------------------------------------|--------------------------------------|
| 司天 | Sovereign Heaven | the 3rd guest qi-step governing the first half of the year |
| 在泉 | Earthly Spring | the 6th guest qi-step governing the second half of the year |
| 岁运 | Annual Motion | the five-element motion governing the whole year, determined by the year stem |
| 客主加临 | Guest-Host Interaction | the superposition of guest qi and host qi in the same time period |
| 天符 | Heavenly Concordance | a special year where annual motion element equals sovereign heaven element |

## 5. Writing Checklist

After finishing each chapter, check terminology according to the following checklist:

* [ ] Did core concepts first appearing in this chapter use the complete format?

* [ ] Are subsequently appearing concepts simplified to Pinyin or English?

* [ ] Are standard symbols used rather than aliases?

* [ ] Are English functional descriptions functional descriptions rather than literal translations?

* [ ] Are original concepts of this book marked with "[Original]"?

* [ ] Is Pinyin without tone marks and with first letter capitalized?

* [ ] Are Chinese characters italicized and enclosed in parentheses?

* [ ] Does the glossary at the end of the book include all new concepts in this chapter?
